# Herna vědomostí

Sázkový kvíz pro prezentaci „Z herny na trh práce“ (VPV231Z, IVP ČZU).

- `host.html` – obrazovka pro projektor (vytvoří místnost s QR kódem)
- `index.html` – stránka pro hráče na mobilu

Pravidla: každý začíná s 1 000 žetony a před každou otázkou vsadí část žetonů na jednu odpověď.
Správně = sázka × násobitel otázky, špatně = sázka je pryč, kdo nevsadí, ztratí minimální sázku.
Nula žetonů = bankrot a hráč dál jen sleduje.

Otázky se správnými odpověďmi nejsou v tomto repozitáři. Vkládají se až na obrazovce projektoru.
